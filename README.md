# Git Lab Commands

Tap-to-copy Git commands for Experiments 1 to 5 (Project Management with Git, 1BCSL307A).

- `index.html` – the whole site in one file. Quick / With explanations switch, expected output for each command, Copy all and an AI prompt button per experiment.

## Push to GitHub

```
git init
git add .
git commit -m "Add Git lab commands page"
git branch -M main
git remote add origin https://github.com/<your-username>/git-lab-commands.git
git push -u origin main
```

Create an empty repository named `git-lab-commands` on GitHub first. To host it, open Settings > Pages, choose the `main` branch and `/ (root)`, then save.
